# Refine the trip details window

## What changes
- Rework the trip details window into a stable screen-height layout with a fixed heading and summary.
- Make only the student section scroll, so long lists remain easy to browse without pushing the window off-screen.
- Improve spacing, alignment, wrapping, and mobile sizing while preserving all existing trip data and statuses.

## Verification
- Open a completed trip with many students and confirm the heading and summary remain visible while the student list scrolls.
- Check desktop and mobile sizes for clipping, overlap, and readable Arabic text.
